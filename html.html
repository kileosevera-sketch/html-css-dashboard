Introduction to HTML

🌐 What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It provides the structure and content of websites by using a system of tags and elements.

Think of HTML as the skeleton of a web page - it defines the basic structure, but CSS adds the styling!

🏷️ How HTML Works

HTML works by using tags - these are enclosed in angle brackets like <tag>. Most tags come in pairs: an opening tag and a closing tag.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

📚 Basic HTML Structure

  • <!DOCTYPE html> - Declares this is an HTML5 document
  • <html> - Root element that wraps all content
  • <head> - Contains metadata and information about the page
  • <title> - Sets the page title (shown in browser tab)
  • <body> - Contains the visible page content
